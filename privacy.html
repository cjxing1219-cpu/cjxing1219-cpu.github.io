Privacy Policy

Anime Thai Analytics · Last updated: October 22, 2026

Anime Thai Analytics ("the app") is a private desktop tool run by a single operator to manage that operator's own YouTube channels. This policy explains what Google user data the app accesses, how it is used, and how it can be removed.

Who uses the app

The app is not available to the public. The only people who sign in are the operator and accounts the operator controls. It does not collect data from viewers or from any other YouTube users.

Data the app accesses

With the operator's permission through Google OAuth, the app may access the following for the authorized channels only:

  • Channel identity: channel ID and title, used to confirm the correct channel is connected.
  • Video data: upload list, titles, publish times, privacy and processing status, and uploaded file name and size.
  • Statistics and YouTube Analytics reports: for example views, watch time, and average view percentage.
  • Upload and scheduling actions requested by the operator for their own videos.

How the data is used

  • To upload and schedule the operator's videos.
  • To match each published video with the local production record it came from.
  • To show the operator how their videos perform, so they can improve future videos.

The app does not use Google user data for advertising, does not sell it, and does not transfer it to third parties. It does not use the data to train AI or machine-learning models.

Storage and security

OAuth tokens and retrieved data are stored only on the operator's own Windows computer. Tokens are encrypted with the Windows user's data protection (DPAPI). Nothing is uploaded to a server run by the app; the app communicates only with Google's official APIs.

Retention and deletion

Data is kept locally for as long as the operator needs it for performance tracking. The operator can delete it at any time by removing the app's local data folder. Access can be revoked at any time from Google Account permissions, which immediately stops the app from accessing the account.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
